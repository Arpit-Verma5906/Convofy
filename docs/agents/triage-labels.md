# Triage labels

Use these upstream default role names as local ticket `Status:` values during
triage. They have not been created as GitHub labels.

| Role | Project label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Implementation workflows may additionally use `claimed` and `resolved` as
described in `issue-tracker.md`.
